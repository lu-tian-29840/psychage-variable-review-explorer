# HRS 2014 · Biopsychosocial Characteristics

## Variable Selection and Measurement Plan

This interactive explorer documents the survey-variable review and the measures to be used in the modeling analysis.

- 211 Core + 375 Leave-Behind variables = 586 survey variables reviewed.
- 546 variables represented in measures + 3 used only for checking + 37 not selected = 586.
- 126 Core measures + 118 Leave-Behind measures = 244 distinct modeling measures.

The measures comprise 125 original-response measures (51.2%), 57 RAND-prepared measures (23.4%), and 62 project-derived measures (25.4%). Each measure is counted once by how its final value is obtained. The social-network composition count is classified as project-derived because it combines four survey responses.

### Explore

1. **How we chose the variables:** selection flowchart, proportional flow, counts and reasons.
2. **Browse survey variables:** related questions grouped by topic.
3. **Measures planned for analysis:** questions, response values, operationalization, construction rules, scientific rationales and publication evidence.

Click counts, petals, category labels or measures to explore details. Search, filters, pagination, browser Back/Forward and URL-fragment links are supported. The pie categories filter the measure list.

### Public-release boundary

This website contains variable-level metadata, survey documentation, measurement definitions and aggregate coverage information—not participant records. It does not calculate participant scores or run a model. Specific scientific limitations are preserved.

Local-only research-document links are omitted because those files are not hosted here. The self-contained explanations and publication DOI links remain. This is a project measurement plan, not an official HRS or RAND product. Survey documentation originates from the Health and Retirement Study; RAND measures are described using RAND HRS documentation. Publication links explain what each cited study supports and any limits on that support.

### Website files

Keep the eight HTML/CSS/JavaScript files together in the publishing directory. The website requires no build step, downloaded fonts, external scripts or respondent datasets.
